# 小红书运营工作台

这是面向画室的小红书运营工作台，不依赖 Autoxhs 源码。它覆盖美术知识分享、画室/学员作品分享和兴趣活动策划。账号规范、草稿、审核结果和排期保存在当前文件夹的 `studio.sqlite3`，图片保存在 `media/`。

## 启动

Windows 可运行 `run.ps1`。首次启动时会创建项目自己的 Python 环境并安装依赖。也可以在 PowerShell 手动运行：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## 发布为可分享网址

这个项目是 Streamlit 应用。部署到 Streamlit Community Cloud 后会获得一个可分享的 `*.streamlit.app` 网址。部署需要你自己的 GitHub 和 Streamlit 账号，本机目前没有已登录的 GitHub CLI，因此不能替你把源码推送到账号或创建线上应用。

1. 将本文件夹中的应用源码上传到你自己的 GitHub 仓库。不要上传 `.venv`、`studio.sqlite3`、`media/` 或任何 API Key。
2. 在 Streamlit Community Cloud 选择该仓库和 `app.py` 部署。
3. 在应用的设置中添加 Secrets，内容为 `PUBLIC_APP = true` 和 `APP_PASSWORD = "设置一个仅分享给可信成员的密码"`。没有设置访问密码时，共享部署会锁定页面。
4. 部署完成后复制平台提供的 `*.streamlit.app` 网址给成员，并单独发送访问密码。

配置 `APP_PASSWORD` 后，网页会要求输入访问密码。工作台内的账号设置、草稿和素材属于同一个共享实例，持有访问密码的人都能看到和修改。Streamlit Community Cloud 的本机文件存储不适合作为长期数据库，重启或重新部署后数据库和上传素材可能丢失。API Key 仅在各自浏览器会话中使用，不应写进仓库或 Secrets。

首次打开后，在左侧填写 OpenAI API Key，再到「账号规范」保存账号定位、目标读者和内容规则。API Key 只留在当前运行会话，不会写入数据库。

「生成内容」可以按主题写一篇，也可以根据本周重点批量生成计划篇数的草稿。草稿需要逐篇审核，通过后可加入发布计划。排期是本机日历记录，发布时打开小红书创作中心，检查内容后手动发布。

## 当前功能边界

- 支持账号规范、主题生成、AI 文本审核、修改、草稿保存、排期记录和 Markdown 导出。
- 美术知识草稿可记录来源链接和依据，活动草稿包含日期、时间、对象、地点、费用、名额及报名方式。
- 作品素材收件箱保存本机图片，并记录作品背景及展示授权确认。
- 活动草稿可单独请求 DALL·E 生成插画，再由工作台把活动标题与信息排成 PNG 海报；图片生成会消耗 OpenAI API 额度。
- 目前没有微信连接器。微信群图片请先在电脑微信中另存，再上传到「作品素材」收件箱。
- 小红书扫码登录与发布使用 `xhs` 社区客户端接口，平台改版后可能失效。扫码会话只保存在当前工作台运行会话中。
- AI 审核是辅助检查，不核实外部事实或图像，也不保证平台审核结果。
- 小红书登录和无人值守发布不包含在此工作台中。发布走官方创作中心的人工确认流程。
